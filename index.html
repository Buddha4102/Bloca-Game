GUIDE COMPLET — MISE EN PLACE UNITY

BLOC A

Guide pas-à-pas pour installer Unity et faire tourner le prototype prison RP en 30 minutes.

1. INSTALLATION UNITY

ÉTAPE 01
Télécharger Unity Hub
Va sur unity.com/download et télécharge Unity Hub.
C'est gratuit. C'est le gestionnaire de versions Unity.

Une fois installé, ouvre Unity Hub → onglet "Installs" → "Install Editor"
→ Choisis la version Unity 2022.3 LTS (la plus stable).

Modules à cocher lors de l'installation :
✅ Android Build Support (pour mobile)
✅ iOS Build Support (si tu as un Mac)
✅ Windows Build Support
✅ Visual Studio (éditeur de code gratuit)
ÉTAPE 02
Créer le projet
Dans Unity Hub → "New Project"
→ Template : 3D (Core) (pas URP pour l'instant)
→ Nom du projet : BlocA
→ Location : ton bureau
→ Clic "Create Project"

Unity s'ouvre. C'est normal si ça prend 2-3 minutes la première fois.

2. STRUCTURE DU PROJET

Une fois le projet ouvert, crée cette structure de dossiers dans l'onglet Project :

Assets/
├── Scripts/
│ ├── Core/
│ │ └── GameManager.cs
│ ├── Player/
│ │ ├── PlayerController.cs
│ │ └── PlayerStats.cs
│ ├── NPC/
│ │ └── NPCController.cs
│ └── Systems/
│ ├── GameSystems.cs (MissionManager + GangSystem + ZoneManager + etc.)
│ └── UIManager.cs
├── Scenes/
│ └── MainGame.unity
├── Prefabs/
├── Materials/
└── Audio/
✅ ASTUCE : Copie les fichiers .cs fournis directement dans les dossiers correspondants via l'Explorateur Windows / Finder. Unity les détecte automatiquement.

3. PACKAGES À INSTALLER

Dans Unity : Window → Package Manager → installe ces packages :

CINEMACHINE
Caméra 3ème personne professionnelle. Déjà dans Unity Registry. Requis pour le suivi du joueur.
INPUT SYSTEM
Gestion des touches clavier/manette/tactile unifiée. Remplace l'ancien Input.GetAxis.
TEXTMESHPRO
Texte haute qualité pour tout le HUD. Import les exemples TMP quand Unity le demande.
AI NAVIGATION
NavMesh pour le pathfinding des PNJ. Requis par NPCController. Dans le Registry Unity.

4. CRÉER LA SCÈNE

ÉTAPE 01
Créer le terrain de base
Dans la Hierarchy → Clic droit → 3D Object → Plane
Scale : X=5, Y=1, Z=10 (couloir principal)
Renomme-le "Corridor_Floor"

Ajoute plusieurs Planes pour les cellules, la cour, la cafétéria.
Utilise des Cubes pour les murs (Scale Y=3 pour hauteur).
ÉTAPE 02
Configurer le NavMesh
Sélectionne tous les Planes de sol → dans l'Inspector → coche "Navigation Static"
Puis : Window → AI → Navigation → onglet "Bake" → clic "Bake"
Tu verras une surface bleue apparaître = zone de déplacement des PNJ. ✅
ÉTAPE 03
Créer le joueur
Hierarchy → Create Empty → Renomme "Player"
Ajoute ces composants dans l'Inspector :
• Character Controller (radius 0.4, height 1.8)
• PlayerController.cs (drag depuis Scripts/)
• PlayerStats.cs
• Animator
• Tag : "Player"

Ajoute un enfant Capsule pour le visuel (3D Object → Capsule).
ÉTAPE 04
Caméra 3ème personne
Sélectionne la Main Camera
Dans PlayerController → champ "Camera Transform" → glisse la Main Camera

OU utilise Cinemachine (recommandé) :
• Cinemachine → Create Virtual Camera
• Follow : Player
• Look At : Player
• Body : 3rd Person Follow
• Shoulder Offset : X=0.5, Y=1.5, Z=-4
ÉTAPE 05
Créer un PNJ
Hierarchy → Create Empty → "NPC_Marco"
Composants à ajouter :
• Nav Mesh Agent (speed 2, radius 0.4)
• NPCController.cs
• Animator
• Layer : "NPC" (crée ce layer dans Edit → Project Settings → Tags and Layers)

Configure dans l'Inspector :
• NPC Name : "Marco"
• Nickname : "Lame"
• Faction : "Los Diablos"
• Relationship : -20
• Wander Radius : 5
ÉTAPE 06
Game Manager
Create Empty → "GameManager"
Ajoute tous les scripts système :
• GameManager.cs
• MissionManager.cs
• EconomyManager.cs
• GangSystem.cs
• ZoneManager.cs
• UIManager.cs
• TikTokManager.cs
• EventManager.cs

Dans l'Inspector de GameManager, glisse chaque composant dans son champ correspondant.

6. ASSETS GRATUITS RECOMMANDÉS

🎭 MIXAMO.COM
Personnages + animations 3D gratuits. Télécharge un personnage low-poly avec animations Walk, Run, Idle, Attack.
🏗️ UNITY ASSET STORE
Recherche "Prison Kit Free" ou "Modular Prison" pour les assets de bâtiment. Beaucoup de packs gratuits.
🕹️ SKETCHFAB.COM
Modèles 3D gratuits exportables en .fbx pour Unity. Cherche : "prison cell", "prison bars", "bed".
📱 JOYSTICK PACK
Asset Store → cherche "Joystick Pack" (gratuit, Indie Marc). Ajoute un FloatingJoystick pour le mobile.

7. BUILD ET PUBLICATION

PC / Steam
Build Windows
File → Build Settings → Windows → Build
Génère un .exe. Tu peux le déposer sur itch.io immédiatement.
MOBILE
Build Android
File → Build Settings → Android → Switch Platform
Player Settings → Package Name : com.tonnom.bloca
Build → génère un .apk à installer sur ton téléphone.

Pour itch.io : zippe le .exe + les fichiers Data et dépose le zip.
WEB (GRATUIT)
WebGL pour Navigateur
File → Build Settings → WebGL → Build
Dépose le dossier sur Netlify Drop ou itch.io
Jouable directement dans le navigateur, sans rien installer !

8. MULTIJOUEUR (ÉTAPE SUIVANTE)

Une fois le prototype solo fonctionnel :

1. Télécharge Photon PUN 2 (gratuit jusqu'à 20 joueurs simultanés)
→ Asset Store → cherche "PUN 2 Free"

2. Crée un compte sur photonengine.com → récupère ton App ID gratuit

3. Dans Unity → Window → Photon Unity Networking → PUN Wizard
→ Entre ton App ID → Setup Project

4. Ajoute PhotonView sur ton Player Prefab
5. Ajoute PhotonTransformView pour synchroniser les positions
6. Ajoute PhotonAnimatorView pour les animations
⚠️ Le multijoueur se développe EN DERNIER, après que le solo est stable. Ne commence pas par là.
